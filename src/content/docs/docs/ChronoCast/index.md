---
title: 'ChronoCast とは？'
---

ChronoCastは、イベントの館内放送における定時放送を自動化するWebサービスです。

イベント主催者や音響担当者が、あらかじめ設定したスケジュールに沿って館内放送を行えるようにします。

ブラウザ上で動作するため、専用のアプリケーションをインストールする必要はありません。

## 利用環境

以下の OS で動作確認を行っています。

- Windows
- macOS
- Android
- iOS

利用にはインターネット接続が必要です。

## 端末について

ChronoCastでは、放送に使用する「送出端末」と、放送を操作する「操作端末」を分けて使用できます。

例えば、会場の音響設備に接続したPCを送出端末として設置し、スタッフが手元のスマートフォンから放送を操作するといった使い方ができます。

送出端末と操作端末を同じ端末にして使用することも可能です。
